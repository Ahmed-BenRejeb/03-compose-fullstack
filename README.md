# 03 – Full stack with Docker Compose 🐳

Frontend (nginx) → Backend (Flask) → Database (PostgreSQL)

## Get the project
```bash
git clone https://github.com/Ahmed-BenRejeb/03-compose-fullstack.git
cd 03-compose-fullstack
```

## Run it
```bash
docker compose up -d --build
```
Open http://localhost:8080

Stop it: `docker compose down`

## Get updates later
```bash
git pull
```
